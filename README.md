# Workout App

En mobilapplikasjon for å planlegge, gjennomføre og holde oversikt over treningsøkter.

Prosjektet utvikles som et personlig porteføljeprosjekt med fokus på mobilutvikling, brukeropplevelse og håndtering av data.

## 🚧 Status

**Prosjektet er i en svært tidlig utviklingsfase.**

Repositoryet er opprettet for å ha prosjektet versjonert og tilgjengelig på GitHub mens utviklingen pågår. Funksjonalitet, struktur og UI vil bli bygget ut fortløpende.

## ✨ Planlagt funksjonalitet

- Opprette treningsøkter
- Velge øvelser til treningsøkter
- Redigere og slette treningsøkter
- Registrere sett, repetisjoner og vekt
- Historikk over tidligere treningsøkter
- Statistikk og progresjon
- Forbedringer av UI/UX

## 🛠️ Teknologier

- React Native
- Expo
- TypeScript
- Expo Router

## 🚀 Komme i gang

Installer dependencies:

```bash
npm install
```

Start utviklingsserveren

```bash
npx expo start
```
